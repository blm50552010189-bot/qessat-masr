قصة عن مصر — نسخة واجهة أولية

ماذا تحتوي هذه النسخة؟
- شاشة افتتاحية بخلفية مصرية.
- زر تشغيل الموسيقى يدويًا (المتصفحات قد تمنع التشغيل التلقائي).
- واجهة رئيسية عربية/إنجليزية.
- أقسام العصور المصرية.
- نافذة تسجيل دخول شكلية فقط.

مهم:
هذه نسخة واجهة تجريبية وليست تطبيقًا متصلًا بقاعدة بيانات بعد.
تسجيل الدخول ولوحة الإدارة وحفظ القصص تحتاج في المرحلة التالية إلى إعداد Supabase
وتفعيل صلاحيات قاعدة البيانات (RLS) وعدم وضع مفاتيح سرية داخل ملفات الواجهة.

للمعاينة:
افتح index.html في متصفح حديث. قد لا تعمل بعض خصائص التثبيت PWA محليًا؛
يلزم استضافة الموقع عبر HTTPS لإتاحته كتطبيق قابل للتثبيت.
